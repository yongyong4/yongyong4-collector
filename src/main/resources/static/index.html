1. 수집 작업 — 지금 잘 돌고 있나?

    
예시

    
    
      
  • 수집 중 수집 시간대이고 최근 수집이 제때 성공함
    • 
      
  • 지연 수집 시간대인데 간격×2 이상 성공 기록이 없음 → 아래 최근 오류 확인, 서버 로그 확인
    • 
      
  • 수집 시간 아님 그 작업의 요일·시간대 밖 (정상)
    • 
      
  • 위치 / 도착 줄의 243 / 605회 는 오늘 호출 수 / 하루 예상 호출 수. 시간대가 끝나면 예상치와 같아야 정상입니다.
        막대는 진행률, 오른쪽은 저장된 행 수와 마지막 성공 시각.
    • 
      
  • 평일에는 작업 두 개가 함께 돕니다. express-morning 06:00~10:00 위치+도착, express-tail 10:02~10:30 위치만.
        10시 직전에 "20분 뒤 도착"으로 예측된 버스가 실제로 언제 왔는지 확인하려고 위치를 30분 더 수집합니다.
        주말(토·일)에는 express-weekend 10:00~15:00 위치+도착 하나만 돕니다 (점심 시간대 혼잡 확인용).
    • 
      
  • 카드 위 오늘 호출 한도 막대는 인증키·API 별로 오늘 쓴 호출 수(재시도 포함)입니다. 같은 키를 쓰는 작업은 합산되며,
        세로선이 오늘 예상치(평일 위치 680·도착 605, 주말 각 755)입니다. 한도 1,000 에 가까워지면 주황/빨강으로 바뀌고, 한도에 닿으면 수집기가 스스로 호출을 멈춥니다.
    • 
    


    
2. 최근 14일 — 하루도 안 빠졌나?

    
예시

    
    
      
  • 평일 정상치: express-morning 위치·도착 각각 605회(121주기 × 5곳), express-tail 위치 75회(15주기 × 5노선). 주말 정상치: express-weekend 위치·도착 각각 755회(151주기 × 5곳). 예상보다 적으면 주황 숫자로 표시됩니다.
    • 
      
  • 위 예시의 10/29 는 위치 호출이 590회 → 약 3주기가 빠졌다는 뜻. 그날 실패 수나 서버 재시작 여부를 확인하세요.
    • 
      
  • 주말은 수집하지 않으므로 행이 없습니다. 수동 수집을 누르면 그날 호출 수에 10회씩 더해집니다.

3. 노선별 버스 위치 — 버스가 어디에, 자리가 몇 석?

    
예시 · 5000번

    
    
      
  1. 위 굵은 선 = 서울행(기점 남동차고지 → 회차 지점 서울역). 우리가 분석하는 구간입니다. 왼쪽 끝이 기점, 오른쪽 끝이 회차 지점.
    2. 
      
  2. 아래 흐린 선 = 회차 후(서울역 → 용인으로 돌아오는 중). 참고용으로 회색 표시.
    3. 
      
  3. ①~⑤ 눈금 = 수집 대상 정류장. 선 아래 범례에 이름과 노선 내 순번(#)이 있습니다. 같은 정류장은 모든 노선에서 같은 번호.
    4. 
      
  4. 박스 위 작은 숫자 = 차량번호 끝 4자리(예: 경기78아1037). 같은 번호면 같은 버스입니다.
        박스를 누르면 그 차량에 테두리가 생기고 따라가기 상태가 됩니다. 과거 보기에서 ◀ ▶ 나 재생으로 넘겨도 계속 강조되어,
        한 대가 정류장을 지나며 좌석이 줄어드는 과정을 쫓을 수 있습니다. 도착 예정 표의 같은 차량 줄도 함께 강조됩니다.
    5. 
      
  5. 박스 아래 큰 숫자 = 남은 좌석. 파랑은 여유, 주황은 10석 미만, 빨강 0은 만석(정류장을 그냥 지나칠 수 있음), ?는 좌석 정보 없음.
    6. 
      
  6. 예시 읽기: ③ 강남대역 바로 뒤 8 → 강남대역에서 많이 타서 8석 남음. ⑤ 신갈 뒤 0 → 고속도로 진입 전에 만석.
        왼쪽 70·52 는 기점 근처라 아직 여유.
    7. 
      
  7. 박스에 마우스를 올리면 차량번호·현재 정류장·좌석이 보이고, 버스 목록 보기를 펼치면 표로 볼 수 있습니다.
    8. 
      
  8. 버스가 하나도 없으면 "운행 중인 버스 없음" — 예: 5005(거점)은 06:40~07:20 외에는 항상 비어 있는 게 정상.
    9. 
    


    
4. 정류장 도착 예정 — 내 정류장에 언제, 몇 석으로?

    
예시 · 29307 강남대역.강남대입구

    
    
      
  • 정류장마다 대상 노선의 다음 버스 2대(두 번째는 "(다음)")를 보여줍니다.
    • 
      
  • 예시 첫 줄: 5000번이 3분 뒤, 2정류장 전(동백2동행정복지센터 부근)에 있고, 지금 6석 남음.
    • 
      
  • 5001A 의 "(다음)" 줄 0 → 두 번째로 오는 차는 이미 만석.
    • 
      
  • 이 예정 시간과 위치 데이터로 계산한 실제 도착 시각을 비교해 예측 오차를 학습합니다.

5. 과거 기록 보기 — 그날 아침엔 어땠나?

    
예시
      

        

        날짜 2026-10-28◀ ━━━━●━━━━━━━━━━ ▶07:14재생
        38 / 121번째 수집 · 호출 10회
      

    

    
    
      
  • 보는 시점에서 과거 보기를 누르고 날짜를 고르면, 아래 노선별 버스 위치와 정류장 도착 예정이 그 날짜의 기록으로 바뀝니다.
        과거 보기 중에는 시점 영역 테두리가 주황색이고, 각 영역 제목에 2026-10-28 (수) 07:14 기록 처럼 시각이 붙습니다.
    • 
      
  • 슬라이더나 ◀ ▶ 로 2분 단위 수집 시각을 넘깁니다. 재생을 누르면 1.2초마다 다음 수집으로 넘어가며 버스가 움직이고 좌석이 줄어드는 것을 볼 수 있습니다.
    • 
      
  • 예시 읽기: 07:10 → 07:14 → 07:18 로 넘기며 5000번 한 대를 따라가면, ③ 강남대역을 지나면서 좌석이 24 → 8 로, ⑤ 신갈 직전에 0 이 되는 식으로 만석이 되는 정류장을 눈으로 확인할 수 있습니다.
    • 
      
  • 최근 14일 표에서 날짜 줄을 눌러도 그날 기록으로 바로 이동합니다. 실시간을 누르면 다시 최신 화면으로 돌아옵니다.
    • 
      
  • 정확한 분석은 CSV 로 받아서 하세요. 이 화면은 "그날 무슨 일이 있었나" 를 빠르게 훑어보는 용도입니다.
    • 
    


    
6. 관리 버튼

    
    
      
  • 지금 1회 수집: 시간대와 상관없이 바로 한 번 수집합니다 (위치 5회 + 도착 5회). 설치 직후 동작 확인, 설정 변경 후 테스트용.
        몇 초 뒤 화면이 자동으로 갱신됩니다. 하루 호출 한도(API 별 1,000회)에 포함되니 남발하지 마세요.
    • 
      
  • ID 다시 변환: 설정 파일의 노선번호·정류소번호를 API 로 routeId·stationId 로 다시 바꿔 저장합니다.
        노선·정류장을 추가하거나 바꾼 뒤에만 쓰면 됩니다. 결과 표에 다음 정류장이 나오니 방향(서울행)이 맞는지 눈으로 확인하세요.

  • 텔레그램 알림 테스트: 설정된 텔레그램 대화방으로 테스트 메시지를 보냅니다. VM 배포 직후 알림이 오는지 확인할 때 쓰세요.

7. CSV 내보내기

    
    
      
  • 미리보기를 누르면 내려받지 않고 페이지 안에서 표로 봅니다(100행씩, 이전/다음으로 넘김, 전체 행 수 표시). 내용이 맞으면 같은 줄의 다운로드를 누르세요.
    • 
      
  • 미리보기 머리글은 한국어 이름 아래에 실제 컬럼명(CSV·pandas 에서 쓰는 영문)이 작게 적혀 있습니다. 상태·코드 컬럼은 머리글에 마우스를 올리면 값의 뜻이 나옵니다.
    • 
      
  • 날짜를 고르고 다운로드를 누르면 그날 데이터가 내려받아집니다. route_master 등 기준표는 날짜 무관 전체.
    • 
      
  • 여러 날을 받을 땐 기간 한 번에 받기: 시작·끝 날짜와 표를 고르고 ZIP 다운로드를 한 번 누르면
        bus_location_2026-10-28.csv, bus_location_2026-10-29.csv … 처럼 일자별 CSV 가 zip 하나로 받아집니다.
        수집이 없던 날(주말 이전·공백일)은 파일이 없습니다. 전체 기간은 첫 수집일부터 오늘까지.
    • 
      
  • bus_location = 2분마다 운행 중인 버스마다 1행(위치·좌석), bus_arrival = 정류장별 도착 예정, api_call_log = 호출 기록(성공/실패).
    • 
      
  • 엑셀에서 한글이 깨지면 엑셀용(BOM) 을 체크하고 다시 받으세요. pandas 는 체크하지 않은 파일이 편합니다.
    •
